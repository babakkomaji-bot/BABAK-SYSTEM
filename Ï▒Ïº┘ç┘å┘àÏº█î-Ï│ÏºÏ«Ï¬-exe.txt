راهنمای ساخت فایل نصبی ویندوز (exe) برای برنامه سامانه بابک
========================================================

این پوشه دو روش برای ساخت فایل exe دارد:

  روش ۱ (پیشنهادی اگر با خطاهای شبکه/فیلترینگ مواجه‌اید):
    ساخت آنلاین با GitHub Actions — نیازی به npm install روی سیستم شما نیست.
  روش ۲:
    ساخت محلی روی خود ویندوز با Node.js.


=========================================================
روش ۱ - ساخت آنلاین و رایگان با GitHub Actions (پیشنهادی)
=========================================================
این روش کل فرآیند ساخت exe را به سرورهای گیت‌هاب می‌سپارد، یعنی هیچ‌کدام از
دستورات npm روی کامپیوتر خودتان اجرا نمی‌شود و مشکلات فیلترینگ/schannel که
دیدید اصلاً مطرح نیست. یک فایل آماده به اسم build.yml داخل این پوشه
(در مسیر .github/workflows/build.yml) گنجانده شده که این کار را خودکار انجام
می‌دهد.

مرحله ۱ - ساخت حساب گیت‌هاب
------------------------------
اگر حساب ندارید، به آدرس زیر بروید و رایگان ثبت‌نام کنید:
https://github.com/signup

مرحله ۲ - ساخت یک مخزن (Repository) جدید
-------------------------------------------
1. بعد از ورود، روی علامت + بالای صفحه بزنید و "New repository" را انتخاب کنید.
2. یک اسم دلخواه بدهید (مثلاً babak-system) و روی "Create repository" بزنید.
   (نیازی نیست Public یا Private بودنش را تغییر دهید؛ هر دو کار می‌کنند.)

مرحله ۳ - آپلود فایل‌های این پوشه
------------------------------------
1. در صفحه‌ی مخزنی که ساختید، روی لینک "uploading an existing file" کلیک کنید
   (یا از منوی Add file گزینه‌ی "Upload files" را بزنید).
2. تمام فایل‌ها و پوشه‌های داخل babak-system-desktop (شامل main.js,
   preload.js, index.html, customer-display.html, package.json، و پوشه‌ی
   مخفی .github) را بکشید و در همان صفحه رها کنید.
   نکته: پوشه‌ی .github معمولاً مخفی است؛ اگر مرورگرتان اجازه‌ی کشیدن پوشه‌ی
   مخفی را نداد، کل پوشه‌ی babak-system-desktop را فشرده (zip) نکرده و به‌جای
   آن یک‌بار کل پوشه را در File Explorer انتخاب کنید (Ctrl+A) و همه را با هم
   بکشید؛ فایل مخفی build.yml هم داخلش همراه می‌آید.
3. پایین صفحه دکمه‌ی سبز "Commit changes" را بزنید.

مرحله ۴ - اجرای خودکار ساخت
-------------------------------
1. به تب "Actions" در بالای صفحه‌ی مخزن بروید.
2. یک اجرا (workflow run) به اسم "Build Windows Installer" را می‌بینید که
   خودش شروع شده (یا اگر نشده، روی آن کلیک کنید و دکمه‌ی "Run workflow" را
   بزنید).
3. صبر کنید (حدود ۳ تا ۶ دقیقه) تا علامت آن به تیک سبز ✓ تبدیل شود.

مرحله ۵ - دانلود فایل exe
-----------------------------
1. روی همان اجرای تکمیل‌شده کلیک کنید.
2. پایین صفحه، بخش "Artifacts" را پیدا کنید و روی
   "babak-system-installer" کلیک کنید تا دانلود شود.
3. فایل دانلودشده یک zip است؛ آن را باز کنید — فایل exe نصبی داخلش است.


=========================================================
روش ۲ - ساخت محلی روی ویندوز
=========================================================
اگر ترجیح می‌دهید مستقیم روی سیستم خودتان بسازید (و مشکل شبکه ندارید)،
مراحل زیر را دنبال کنید. کل کار حدود ۵ تا ۱۰ دقیقه طول می‌کشد و نیازی به
برنامه‌نویسی ندارد.

مرحله ۱ - نصب Node.js
-----------------------
اگر Node.js روی سیستم‌تان نصب نیست، از آدرس زیر نسخه‌ی LTS را دانلود و نصب کنید:
https://nodejs.org

مرحله ۲ - باز کردن پوشه پروژه در خط فرمان
-------------------------------------------
1. این پوشه (babak-system-desktop) را در جایی روی ویندوز کپی کنید.
2. داخل پوشه راست‌کلیک کنید و گزینه‌ی "Open in Terminal" یا "Open PowerShell window here" را بزنید.

مرحله ۳ - نصب وابستگی‌ها
--------------------------
در ترمینال این دستور را بزنید و صبر کنید تمام شود:

    npm install

مرحله ۴ - ساخت فایل نصبی
--------------------------
سپس این دستور را بزنید:

    npm run dist

بعد از چند دقیقه، یک پوشه به نام dist ساخته می‌شود که داخل آن فایلی مثل زیر قرار دارد:

    dist/سامانه بابک Setup 1.0.0.exe

همین فایل، فایل نصبی نهایی برنامه است. آن را روی هر ویندوزی اجرا کنید تا برنامه
نصب شود و یک آیکون روی دسکتاپ و منوی استارت ایجاد شود.


نمایشگر مشتری (صفحه تاچ دوم)
==============================
از این نسخه به بعد، برنامه دو پنجره باز می‌کند:

1. «صندوق فروش» — پنجره‌ی اصلی که شما (فروشنده) با آن کار می‌کنید: کالا را از
   انبار انتخاب می‌کنید، به سبد خرید اضافه می‌کنید و در پایان «تکمیل و ثبت فروش»
   را می‌زنید.
2. «نمایشگر مشتری» — پنجره‌ی دومی که برای نمایش به مشتری طراحی شده و به‌طور
   خودکار هر تغییری در سبد خرید (اقلام و جمع کل) را زنده نشان می‌دهد، و بعد از
   تکمیل فروش، فاکتور نهایی و مبلغ پرداختی را نمایش می‌دهد.

نحوه اتصال صفحه‌ی تاچ
------------------------
1. صفحه‌نمایش تاچ را با کابل (HDMI/USB-C/VGA به‌همراه کابل تاچ در صورت نیاز) به
   کامپیوتر وصل کنید.
2. در ویندوز به Settings > System > Display بروید و مطمئن شوید حالت نمایش روی
   "Extend these displays" است (نه Duplicate)، تا دو صفحه‌ی مستقل داشته باشید.
3. برنامه را اجرا کنید. اگر ویندوز دو مانیتور را تشخیص داده باشد، پنجره‌ی
   «نمایشگر مشتری» به‌طور خودکار روی مانیتور دوم و به‌صورت تمام‌صفحه باز می‌شود.
4. اگر تشخیص خودکار جواب نداد، پنجره‌ی نمایشگر مشتری را با ماوس به سمت صفحه‌ی
   تاچ بکشید و دکمه‌ی «تمام‌صفحه» بالای همان پنجره را بزنید.

نکته: صفحه‌ی تاچ فقط برای نمایش استفاده می‌شود؛ نیازی به لمس‌کردن آن توسط مشتری
برای انجام کاری نیست — فقط جمع فاکتور و کالاهای خریداری‌شده را می‌بیند. اگر
دوست دارید مشتری هم چیزی روی آن لمس/تایید کند (مثل امضای دیجیتال یا انتخاب
انعام)، این قابلیت را می‌توان در نسخه‌های بعدی اضافه کرد.


پشتیبان‌گیری خودکار
=====================
از این نسخه به بعد، اولین بار که برنامه را باز می‌کنید (یا هر وقت از تنظیمات
بخواهید)، یک پنجره برای انتخاب «پوشه پشتیبان» باز می‌شود. بعد از انتخاب پوشه،
هر بار که در «صندوق فروش» یک فروش را با دکمه‌ی «تکمیل و ثبت فروش» ثبت کنید،
یک فایل به‌روز به اسم babak-backup.json به‌طور کاملاً خودکار در همان پوشه
ذخیره می‌شود — بدون نیاز به هیچ کلیک یا دکمه‌ی جداگانه‌ای.

برای انتقال اطلاعات به دستگاه دیگر، کافی است همین فایل babak-backup.json را
منتقل کنید و از تب «تنظیمات» → «بازیابی از فایل پشتیبان» آن را وارد کنید.

اگر بخواهید پوشه‌ی پشتیبان را تغییر دهید، از تب تنظیمات دکمه‌ی «تغییر پوشه
پشتیبان» را بزنید.


نکات مهم
---------
- اطلاعات انبار، فاکتورها و گردش حساب داخل خود برنامه (روی همان کامپیوتر) ذخیره
  می‌شود، نه در فضای ابری.
- اگر خواستید آیکون اختصاصی برای برنامه بگذارید، یک فایل icon.ico در همین پوشه
  قرار دهید و در package.json داخل بخش "win" این خط را اضافه کنید:
      "icon": "icon.ico"
- برای اجرای سریع بدون ساخت نصبی (مثلاً برای تست): پس از npm install دستور زیر
  را بزنید:
      npm start
